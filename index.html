Изучение UnCo

Простой язык для создания игр

Добро пожаловать в обучающий справочник! Здесь ты шаг за шагом научишься писать код, рисовать графику и создавать собственные игры прямо в браузере.

Введение

#intro

Вся программа в UnCo выполняется сверху вниз, строка за строкой. Чтобы что-то вывести на экран, используется команда print.

# Это комментарий. Он не выполняется.
# Строки ниже — это код.

print("Привет, мир!")
print("Я изучаю UnCo")
Совет: Всё, что написано после символа #, считается комментарием. Это заметки для тебя, программа их не читает.

Переменные

#variables

Переменная — это коробка, в которой ты хранишь данные (числа, текст). В UnCo коробка создаётся словом hold.

# Создаем переменные
hold userName = "Алиса"
hold userAge = 20
hold isAlive = true

# Выводим их на экран
print(userName)
print(userAge)

# Мы можем менять значение
userAge = 21
print(userAge) # Теперь выведет 21

Если ты уверен, что значение меняться не будет, используй lock (замок). Такой код надёжнее.

lock PI = 3.14159
lock MAX_HEALTH = 100

Числа и математика

#math

UnCo умеет делать все базовые математические операции. Вот таблица операторов:

ОператорЧто делаетПример
+Сложение5 + 3 → 8
-Вычитание10 - 4 → 6
*Умножение3 * 4 → 12
/Деление10 / 2 → 5
%Остаток от деления10 % 3 → 1
**Возведение в степень2 ** 3 → 8

Для сложных вычислений есть встроенные функции:

# Квадратный корень
print(sqrt(16))  # 4

# Округление
print(round(3.7)) # 4
print(floor(3.9)) # 3 (вниз)
print(ceil(3.1))  # 4 (вверх)

# Случайное число от 1 до 10
print(random(1, 10))

# Модуль числа (убирает минус)
print(abs(-5))    # 5

Текст (Строки)

#strings

Текст в коде пишется в кавычках (двойных или одинарных).

hold greeting = "Привет"

# Склеивание текста (конкатенация)
print(greeting + ", мир!")

# Узнать длину строки
print(len(greeting)) # 6

# Перевести в верхний регистр
print(upper("привет")) # ПРИВЕТ

# Разбить текст на массив слов
print(split("яблоко, банан, вишня", ", "))

В двойных кавычках можно вставлять переменные прямо в текст с помощью @{}:

hold name = "Иван"
hold age = 25

# Интерполяция строк
print("Меня зовут @{name}, мне @{age} лет.")

Условия

#if-else

Если нужно, чтобы код выполнился только при определённом условии, используется слово when (когда).

hold health = 50

when health > 0 {
    print("Вы живы!")
} else {
    print("Вы проиграли!")
}

Если условий несколько, можно добавить else when (иначе если):

hold score = 85

when score > 90 {
    print("Отлично!")
} else when score > 70 {
    print("Хорошо!") # Сработает это
} else {
    print("Плохо.")
}

Циклы

#loops

Циклы нужны, чтобы повторять код несколько раз.

Цикл loop (выполняется, пока условие верно)

hold i = 0
loop i < 5 {
    print("Итерация: " + str(i))
    i += 1 # Увеличиваем i на 1
}

Цикл each (для массивов)

Если у тебя есть список, ты можешь пройтись по каждому его элементу.

hold fruits = ["яблоко", "банан", "вишня"]

each fruit over fruits {
    print("Я люблю " + fruit)
}

Функции

#functions

Функции — это блоки кода, которые можно вызывать по имени. Они создаются словом task.

# Создаем функцию с двумя параметрами (a и b)
task addNumbers(a, b) {
    hold sum = a + b
    give sum # return (возвращаем результат)
}

# Вызываем её
hold result = addNumbers(5, 10)
print(result) # 15

Если функция просто что-то делает и не должна возвращать результат, слово give не нужно:

task sayHello(name) {
    print("Привет, " + name + "!")
}

sayHello("Аня")
sayHello("Ваня")

Массивы

#arrays

Массив — это список данных. Он создаётся в квадратных скобках [].

hold scores = [10, 20, 30]

# Получить первый элемент (нумерация с нуля)
print(scores[0]) # 10

# Добавить в конец
push(scores, 40)
print(scores) # [10, 20, 30, 40]

# Удалить последний
pop(scores)

Для массивов есть удобные функции, которые позволяют делать сразу много всего:

hold numbers = [1, 2, 3, 4, 5]

# Умножить каждое число на 2
hold doubled = map(numbers, task(n) { give n * 2 })
print(doubled) # [2, 4, 6, 8, 10]

# Оставить только четные
hold evens = filter(numbers, task(n) { give n % 2 == 0 })
print(evens) # [2, 4]

# Сумма всех чисел
print(sum(numbers)) # 15

Объекты

#objects

Если нужно хранить данные не списком, а по ключам (как в словаре), используются объекты. Они создаются в фигурных скобках {}.

hold player = {
    name: "Герой",
    level: 5,
    health: 100
}

# Доступ к данным через точку
print(player.name)  # "Герой"
print(player.level) # 5

# Изменение данных
player.health = 90

# Добавление новых данных
player.mana = 50

Рисование (Холст)

#canvas

Чтобы рисовать, нужно создать холст (canvas). Это твой экран для игры.

# Создаем холст шириной 800 и высотой 600 пикселей
canvas(800, 600)

# Заливаем фон
clear("#111")

# Рисуем круг (x, y, радиус, цвет)
circle(400, 300, 50, "#58a6ff")

# Рисуем прямоугольник (x, y, ширина, высота, цвет)
rect(100, 100, 100, 50, "#f97583")

# Рисуем текст (текст, x, y, размер, цвет)
text("Привет, холст!", 400, 50, 24, "#fff")

Игровой цикл

#game-loop

Чтобы игра "жила" и обновлялась 60 раз в секунду, используется функция onFrame. Внутри неё ты двигаешь персонажей и перерисовываешь экран.

canvas(400, 400)
hold x = 200
hold y = 200

onFrame(task(t, dt) {
    # dt — это время с прошлого кадра (секунды)
    # t — общее время игры
    
    clear("#0a0a0a")
    
    # Двигаем шар вправо
    x += 100 * dt
    
    # Если вышел за край, возвращаем обратно
    when x > 400 {
        x = 0
    }
    
    # Рисуем его
    circle(x, y, 20, "#7ee787")
})
Важно: Умножай скорость на dt (например, 100 * dt). Так твоя игра будет работать с одинаковой скоростью на мощных и слабых телефонах.

Кнопки и UI

#ui-controls

Ты можешь добавлять настоящие кнопки и ползунки поверх игры.

canvas(400, 400)
hold color = "#ff0000"

# Создаем кнопку
# (текст, x, y, ширина, высота, функция при клике)
createButton("Сменить цвет", 20, 20, 150, 40, task() {
    color = "#00ff00"
    print("Цвет изменен!")
})

onFrame(task(t, dt) {
    clear("#111")
    circle(200, 200, 50, color)
})

Основы 3D

#3d-basics

Создать 3D-сцену очень просто. Мы используем библиотеку Three.js, которая встроена в язык.

# Подключаем 3D движок
use "three"

# Создаем сцену
start3D({width: 800, height: 600}).then(task(ok) {
    
    # Добавляем свет
    sun3d("#ffffff", 1.0)
    
    # Создаем куб (x, y, z, ширина, высота, глубина, цвет)
    hold box = sceneBox(0, 0, 0, 2, 2, 2, "#ff6600")
    
    # Включаем игровой цикл для 3D
    onFrame(task(t, dt) {
        
        # Вращаем куб (x-угол, y-угол, z-угол)
        sceneRotate(box, 0, t, 0)
        
        # Обязательно вызываем рендер (отрисовку)
        render3d()
    })
})
